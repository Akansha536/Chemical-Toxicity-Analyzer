# 🧪 Chemical Toxicity Analyzer

A web application that predicts the toxicity of chemical compounds using machine learning. The application provides an intuitive interface for entering chemical information and viewing prediction results.

---

## 🚀 Features

- Predicts chemical toxicity
- User-friendly interface
- Machine learning–based predictions
- Fast and responsive design
- Detailed prediction results

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Machine Learning
